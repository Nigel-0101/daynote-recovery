# Daynote recovery

Read-only recovery page for the Daynote origin migration. Only the three known Daynote localStorage keys are inspected. All data stays in the current browser; export files are generated locally. No telemetry, external dependencies, storage writes, upload or automatic import.

Publish this page at https://nigel-0101.github.io/daynote-recovery/ without a CNAME. The original Daynote custom domain and repository remain unchanged. Open this page in the same Chrome profile that originally held the records. Do not publish personal backups or export files in this repository.
